# 夜勤のSOC ｜ NIGHT SHIFT — One Night in the SOC

**あなたは新米SOCアナリスト。深夜0時にシフトが始まり、静かな夜が一件のアラートから崩れていく。**
コマンドを叩き、ログを読み、経路をたどり、散らばった証跡が「一本の線」につながる瞬間を、あなたの手で解き明かす——体験型のインシデントレスポンス・シミュレーションです。

これは、筆者がある実習(全13週)で学んだネットワークとセキュリティの知識を、**一夜のSOC(セキュリティ監視室)体験**として再構成した教材です。知識を「眺める」のではなく、夜を越えるために「使う」ことを狙いにしています。

> 舞台となる企業・IPアドレス・ドメインはすべて**架空**です。IPは文書化用に予約された範囲(RFC5737 / RFC1918)のみを使用しています。実在の事件は、公知の事実として出典つきの「参考カード」として分離・引用しています。

---

## 何が学べるか

一夜の勤務を通じて、ネットワークの土台から、その上に立つセキュリティ、そして技術・法・社会が分けられないことまでを、手を動かしながら体験します。

- **ネットワークの道具**: `whois` で攻撃元IPの登録組織を引く / `ping`・`traceroute` で到達性と距離(RTT)を測る / `curl` で応答を取得する / NAT・NAPT のセッション表を読む
- **脅威と事件**: Mirai型のデフォルトパスワード辞書によるIoT侵入 / DDoS(処理能力を超える要求) / Web改ざんとハッシュ照合によるフォレンジック / AiTM(中間者)フィッシング / キルチェーン(点が線になる)
- **法と倫理**: 通信の秘密、プライバシー権、PL法・NOTICE制度が「その調査、越権では?」という形で調査中に立ち上がります
- **実務フロー**: 検知 → トリアージ → 調査 → 封じ込め → 報告、というインシデントレスポンスの手続きそのものが遊びになります

朝のエンディングでは、あなたが実際に「使った」知識に応じて全13週のチップが点灯し、**一夜の勤務が=学びの総ざらいだった**ことが可視化されます。

## 6つのフェーズ(一夜の時計)

| 時刻 | フェーズ | 内容 |
|---|---|---|
| 00:00 | 静かな夜 | 道具開き。`ping`/`whois`/`traceroute`/`show nat-table` に慣れる |
| 01:00 | 最初のさざなみ | IoT/Mirai の初期侵入。感染機器の認証ログに辞書攻撃の痕跡を見つける |
| 02:30 | 嵐が来る | DDoS。トラフィックとセッションゲージを見ながら緩和策を投入して収める(ミニゲーム) |
| 03:30 | 静かすぎる | Web改ざん。公開JSのMD5ハッシュを基準値と照合し、書き換えられた1件を特定(ミニゲーム) |
| 05:00 | 一本の線 | AiTM/キルチェーン統合。証跡を相関分析にかけ、封じ込め判断を下すクライマックス |
| 06:00 | 朝が来る | 引き継ぎレポートの自動生成、使った知識の点灯、共有カード |

## 実践演習(CHALLENGE)モード

起動画面の「実践演習に挑む」から、**サジェストなしで解く高難度の腕試し(全12問)**に入れます。物語を進めず、実際のインシデント対応で使う「読み・計算・切り分け」だけを単問で試すモードです。

- **出題例**: サブネット(CIDR)の内外判定とホスト数の暗算 / base64・16進で難読化された永続化・Webシェルのデコード / 複数ログの相関によるピボットIP特定 / ホモグリフ(そっくり文字)なりすましドメインの発見 / キルチェーンの並べ替え / IOCハッシュ照合 / TTLからのOS・ホップ推定 / アクセスログからの持ち出し量集計 / SPF・DKIM・DMARCによるなりすまし判定 / UTC↔JSTの時刻相関
- 各問は難易度(★1〜5)・カテゴリ付き。**採点すると正誤に関わらず詳しい解説**と「この技術を学んだ回」が出ます。**段階ヒント**あり。誤答でも正解が示されるので、解けなくても学べます。
- クリア状況はブラウザに保存され、次回も引き継がれます(全12問クリアで称号)。
- 用いるIP・ドメイン・ログはすべて架空(文書用の予約レンジ)。解読対象は攻撃の「痕跡(IOC)」であり、防御・検知の練習を目的としています。

## 操作方法

- **ターミナル**: 中央のワークスペースでコマンドを入力します。`help` で一覧、`↑`/`↓` で履歴、`Tab` で補完。
- **見学モード / 実務モード**: 見学モードは各場面で「次の一手」をサジェスト表示します(クリックで自動実行)。実務モードは自力でコマンドを組み立てます。
- **章ジャンプ**: 起動画面で任意の時刻(フェーズ)から開始できます。クライマックス〈一本の線〉への直行デモも可能です。
- **タブ**: ターミナル / ネットワーク図 / 証跡ボード / 対応(ミニゲーム)を切り替えます。
- **ナレッジ(道具箱)**: 調査で必要になった知識が右パネルに解禁され、カードを開くと詳しい解説が出ます。

主なコマンド: `help` `whois <ip>` `ping <host|ip>` `traceroute <host|ip>` `curl <url>` `show <nat-table|devices|mail|logs <id>>` `inspect <deviceId>` `hash <filePath>` `block <ip>` `isolate <deviceId>` `clear`

隠しコマンド(イースターエッグ)もいくつか仕込まれています。見つけたら、名場面のオマージュです。

## アクセシビリティ

- **キーボードだけで最後までクリア可能**です(コマンド入力主体・タブは矢印キー・`1`〜`4` でタブ切替・`?` でヘルプ・`Esc` でダイアログを閉じる)。
- **`prefers-reduced-motion`** を検知すると、タイプ演出・グラフの動き・線描画アニメを静的な完成状態に置き換えます。起動画面のトグルや上部バーからも手動で切り替えられます。
- ターミナル出力は `aria-live` で読み上げ対象です。ダイアログはフォーカストラップ付き。
- ステータスは**色 + アイコン + 文字**の三重表現で、色覚多様性に配慮しています。
- レスポンシブ: デスクトップは3ペイン、タブレットで2ペイン(ナレッジはドロワー)、モバイルは1カラム + 下部タブバーに再構成されます。

## 技術

- **Vanilla HTML / CSS / JavaScript のみ。ビルド工程なし・依存パッケージゼロ・完全自己完結。**
- 外部CDN・外部フォント・外部画像・ネットワーク通信を一切使いません。すべてのアセット(ネットワーク図のSVGなど)は実行時に生成します。
- データ(知識カード・架空世界・物語)とランタイム(状態・ターミナル・進行・UI・ミニゲーム)を分離し、モジュール間はイベントバス経由でのみ連携します。
- 状態は `localStorage` に自動保存されます。
- モダンブラウザ(Chrome / Edge / Safari 最新)で動作します。

## 公開手順(GitHub Pages)

このフォルダ(`site/`)がそのまま公開ルートになります。

1. このリポジトリを GitHub に push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」にし、公開ブランチと、このフォルダを含むパスを選びます(このフォルダをリポジトリのルートにする場合はルート、サブディレクトリに置く場合はそのパス)。
4. 保存すると、数分で公開URLが発行されます。

Jekyll の処理を無効化するための空ファイル `.nojekyll` を同梱しています。ビルド設定は不要です。

```

  index.html            … 単一ページのSOCコンソール(全DOM骨格)
  .nojekyll             … GitHub Pages で Jekyll を無効化
  css/                  … tokens / base / components / effects(デザイントークンとスタイル)
  js/
    data/               … knowledge(知識カード・週・参考事件) / world(架空世界) / story(物語)
    engine/             … state(状態・イベントバス) / terminal(コマンド) / shift(フェーズ進行)
    ui/panels.js        … アラート・チャット・ナレッジ・証跡・ネット図・法メモの描画
    games/              … ddos / hash / killchain / report(各フェーズのミニゲームと朝の集計)
    a11y.js             … フォーカス管理・キーボード操作・モーション軽減
    main.js             … 起動と全体の結線
```
